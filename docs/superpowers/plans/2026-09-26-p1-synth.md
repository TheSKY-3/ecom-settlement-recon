# P1 造数模块实施计划（账单合成 + 六类埋雷 + 标准答案）

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans（本会话内联执行，用户已授权放手模式）。
> 勾选框（`- [ ]`）跟踪进度。

**Goal:** 从干净底座生成"三本账"（平台账单 + 退款流水是新生成的两本），按六类人为埋雷，产出带标准答案的冻结评测集。

**Architecture:** `src/synth/` 纯函数模块：规则卡 → 生成器（账单/退款）→ 注入器（六类，池子互斥）→ 标准答案 → 编排器（读写 CSV + 自校验）。测试先行，全部可复现（固定随机种子）。

**Tech Stack:** Python 3.12 标准库（csv/random/sqlite3）+ pytest。零第三方运行时依赖。

**Spec:** `docs/superpowers/specs/2026-09-26-recon-agent-design.md`

## Global Constraints

- 金额容差 ±0.005；佣金基准费率 0.20（可配置）；随机种子 SEED=20260926。
- 注入池互斥：一个订单最多中一种雷；避开自然差异订单（金额不一致 576 单名单从 data/olist.db 现算）。
- 干净世界规则：R1 账单只开给非 canceled/unavailable 的有明细订单；R2 应付卖家 = 货款+运费−佣金(率×货款)；R3 取消/不可达且支付已审批 → 全额退款；R4 账单日期 = 审批日+7 天（缺审批用下单日+7），退款日期 = 审批日+14 天（同回退规则）。
- 原始数据只读；产物全部进 `data/synthetic/`（gitignore 的只有 data/raw 与 *.db，synthetic 产物 CSV 不提交、生成器与规范提交）。
- 每个任务：先写测试看它红 → 实现到绿 → 提交。

### Task 5: 六类注入器

**Files:** Create `src/synth/injectors.py`; Test `tests/test_injectors.py`

**Interfaces:**
- 统一签名：`inject_X(bills, payments, refunds, orders_index, pool, rng, counts, gt_rows, gt_seq) -> None`（原地修改三个账本列表并追加 gt_rows；orders_index: order_id→order dict）
- `inject_single_sided`：从 pool 删账单 ×SINGLE_DROP_BILL；造孤儿账单（随机 32 位十六进制 order_id 且不在 orders_index，重复抽样直到足够）×SINGLE_ORPHAN_BILL；从 pool 删整单支付 ×SINGLE_DROP_PAYMENT（删支付子池与删账单子池互斥）
- `inject_amount_mismatch`：费率错（rate→WRONG_RATE 并重算 fee/settlement）×AMOUNT_WRONG_RATE；漏运费（freight_amount→0、settlement=price−fee）×AMOUNT_MISSING_FREIGHT
- `inject_status_inconsistency`：给 pool（canceled/unavailable 有明细单）加合规形状的账单行（按规则卡金额公式）×STATUS_REBILL
- `inject_refund_missing`：从退款表删除 pool 订单的退款 ×REFUND_MISSING
- `inject_duplicate`：复制账单行、bill_id 追加 `_DUP` ×DUPLICATE_BILL
- `inject_version_diff`：原行 version→2、issued_date+1；新增 v1 行（rate=OLD_RATE 重算、原日期、bill_id=f"B_{oid}_1"）×VERSION_DIFF
- 池互斥由调用方保证：`allocate_pools(candidate_orders, config) -> dict[type→order_ids]`（不放回抽样，rng 种子固定）

- [ ] 测试：同种子两次注入结果逐行一致；每类数量精确等于 config；池互斥（无订单中两雷）；每个 gt 行可在脏数据里验证（删账单→该单无账单；孤儿→order_id 不在 orders；费率错→rate==0.10；漏运费→freight==0；状态→该单 status 为 canceled/unavailable 且有账单；退款→退款表查无；重复→同单两行同 version；版本→该单恰两行且 v1.rate==0.15）→ 红 → 实现 → 绿
- [ ] Commit: `feat(synth): 六类注入器`
