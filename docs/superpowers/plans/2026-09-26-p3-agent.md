# P3 Agent 壳实施计划（2026-09-26）

> 设计依据 [2026-09-26-p3-agent-design.md](../specs/2026-09-26-p3-agent-design.md)。TDD，每步绿了才提交。

## 模块与顺序

1. **`src/agent/llm.py`** — `LLMError` / `available()` / `chat(messages, max_tokens)`。urllib 标准库；`_urlopen` 单独命名供测试注入；请求体带 model/messages/max_tokens/effort；HTTP 错误归一为 LLMError（状态码 + 响应体前 200 字，绝不含密钥）。
2. **`src/agent/guardrails.py`** — `check(text, facts) -> {ok, bad_numbers, bad_ids}`。日期先剔除再提数字（日期串本身入允许集）；数值允许集含 x、x×100、x÷100 的多种格式变体（兼容百分比与千分位）；编号正则用环视而非 `\b`（中文紧邻 hex 时 `\b` 失效）。
3. **`src/agent/tools.py`** — 5 个只读工具产出"事实单"：`order_facts`（复用 workbench data 层）、`finding`（全量拉 findings 后按 id 过滤，strip evidence）、`gt`、`stats`、`samples_by_type`。
4. **`src/agent/prompts.py`** — 系统提示（只许用事实单、不得算新数字）+ 各出口的确定性 fallback 文案函数（数字同样取自事实单，白名单自洽）。
5. **`src/agent/loop.py`** — `run_once(kind, question, facts, fallback_answer)`：无 key/超时/API 错/校验不过 → fallback；校验不过带违规清单重试一次（模型往返 ≤2）；每次写一行 JSON 到 `RECON_AGENT_DIR/trace.jsonl`（默认 `output/agent/`，已 gitignore）。
6. **`src/agent/attribute.py` / `ask.py`** — attribute(ref) 走 F/GT/订单号解析；ask(question) 确定性意图路由（订单号→订单事实；F/GT→归因；六类名→统计+例子（模板直答）；统计词→判分摘要（模板直答）；其余→能力话术不调模型）。
7. **工作台接入** — `GET /api/agent/status`、`POST /api/agent/ask`、`GET /api/agent/attribute/{ref}`；前端：概览问答框 + 引擎判定行"归因"按钮。
8. **`scripts/agent_smoke.py`** — 真模型冒烟（手动，不进 pytest）。

## 测试（tests/test_agent.py，全部离线）

- llm×5：无 key available=False；chat 无 key 抛 LLMError；HTTPError 归一；内容提取；请求体字段（model/effort/Authorization）。
- guardrails×5：事实内数字通过；编造数字拦截；未知订单号拦截；百分比等价（1.0→100%）；日期放行。
- tools×3：order_facts 取 conftest 小世界 o2（删账单：bills 0 行）；finding 读手写 findings.json；samples_by_type 过滤。
- attribute×4（注入假 chat）：合规→llm+trace 1 行；编数字重试仍编→fallback+2 次往返；无 key→fallback；未知 ref→固定话术。
- ask×4：32hex 订单意图（用 conftest ORPHAN）；统计词→模板且 chat 未被调；六类名→统计+例子；无意图→能力话术。
