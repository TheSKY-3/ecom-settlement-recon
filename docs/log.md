## 2026-09-26 · P1 评测集冻结（本次）

- **做了什么**：写完造数五件套——平台账单生成器、退款流水生成器、六类埋雷器、标准答案读写、编排器（带自校验）；对 9.9 万单真实底座跑出冻结评测集：干净三本账 + 脏三本账 + **1,750 条标准答案**。规范成文 [injection-spec-v1.md](injection-spec-v1.md)。
- **为什么做**：项目要证明"能对出账、能说清错"，就得先有一张**带标准答案的考卷**。这 1,750 颗雷（六类人为错误）就是全部考题，之后引擎怎么改都考同一套，分数才可比——这叫评测集冻结（freeze）。
- **怎么验证的**：22 个自动化考试全绿（每个模块都先写考试、看它红、再实现到绿）；造数脚本内置自校验（行数守恒、自然差异单绝不被埋雷），不过就报错退出；关键数字与 P0 盘点对上：干净账单 98,199 = 98,666（有明细订单）− 467（取消/不可达有明细单）；退款 1,093 = 484 + 609（P0 的"取消/不可达且已审批"单数）。
- **遗留与下一步**：P2 匹配引擎——拿脏三本账互对、按六类归因、对照标准答案出第一版分数。
